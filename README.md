# WebsiteProject_Margo
Simple responsive website built with HTML and CSS.

# Website Project

This project is a simple and responsive website built using HTML5 and CSS3. The goal was to create a clean and well-structured layout with easy navigation and a modern visual style.

# Technologies

HTML5
CSS3
Responsive layout (Flexbox / Grid)

# Features

Clear and structured page layout
Responsive design for different screen sizes
Navigation between sections
Modern and minimal styling

# Purpose

The project was created to practice front-end development, including page structure, layout design, and CSS styling.

# How to Run

Clone the repository

Open the index.html file in a web browser
